# World-Tech

Sistema web para consulta y administración de dispositivos tecnológicos.

## Tecnologías

- React + Vite
- Node.js + Express
- MariaDB
- Bootstrap

## Ejecución

### Backend - Frontend

```bash
cd BackEnd
npm install
npm run dev
```bash
cd Frontend
npm install
npm run dev
